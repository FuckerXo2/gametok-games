GameTok Web Games SDK (v1.2.0)

Connect your external web game (HTML5, Canvas, Three.js, Phaser, Godot) to GameTok in under 2 minutes. Enable 1-click in-game payments, rewarded ads, and auto-login without hosting your code with us.

1. Include the SDK in your HTML <head>
<script src="https://games.gametok.co/sdk/v1.js"></script>
2. In-App Purchases (80% Creator Payout / 20% GameTok Cut)
// Trigger native GameTok Apple Pay / Card checkout sheet const purchase = await window.GameTok.payments.purchase({ itemId: 'gems_100', title: '100 Gem Pack', amount: 0.99, currency: 'USD' }); if (purchase.success) { console.log('Payment verified! Receipt:', purchase.receiptId); grantPlayerGems(100); }
3. Player Identity (Auto-Login)
const player = await window.GameTok.player.getPlayer(); console.log('Welcome ' + player.username + ' (ID: ' + player.id + ')');
4. Rewarded Video Ads
const ad = await window.GameTok.ads.showRewardedAd(); if (ad.rewarded) { givePlayerExtraLife(); }
5. Global Leaderboard Score Submission
window.GameTok.leaderboards.submitScore(currentScore);
