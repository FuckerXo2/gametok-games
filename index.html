How it works

From your game to the feed in three steps.

01

Bring your game as it is

No SDK, no GameTok code. Any web game works: host it anywhere, or let GameTok host it. Touch controls and a light download get it into the phone feed.

02

Create a draft

Paste your game's link or drop its folder. It opens in a private test player — the real GameTok player, in test mode.

03

Go live

Automatic checks make sure it loads and can be shown inside GameTok. Pass them and your game is in the feed.
