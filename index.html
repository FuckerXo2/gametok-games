How it works

From your game to the feed in three steps.

01

Add one script tag

Load bridge.js so your game fits GameTok's player, pauses when it should and reports scores. Optional, but recommended.

02

Create a draft

Paste your game's link or upload one HTML file. It opens in a private test player — the real GameTok player, in test mode.

03

Go live

Automatic checks make sure it loads and can be shown inside GameTok. Pass them and your game is in the feed.

What you get

Built for web game developers.

Instant updates

GameTok loads your hosted game, so there's nothing to re-upload. Deploy to your site and players have it.

Real analytics

Plays, unique players and session length for every game, in your dashboard.

Players are already signed in

GameTok.init() gives your game the player's name and avatar, and a session your server can verify. No login screen to build.

Test before you go live

Drafts, test API keys and a test player that logs everything your game does and ticks off an integration checklist.
